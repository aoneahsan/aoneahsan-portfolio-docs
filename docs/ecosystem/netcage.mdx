NetCage controls network access for selected Android apps. A rule can target Wi-Fi, mobile data or both; the rest of the phone can stay connected.

**The question:** Can one app go offline without disconnecting the phone?

## What does a rule target?

The selected app and connection type are the decision. That is narrower than switching off Wi-Fi or mobile data for the whole device.

## Can rules repeat?

Profiles group apps and apply rules on chosen days and times. The roster establishes the scheduling capability, while the live product shows how those choices are made.

## What should a visitor check?

A rule should make its target and effect clear before it changes connectivity.

## Why does the target need to be explicit?

A network rule can block Wi-Fi, mobile data or both for one selected Android app while other apps remain online. If the target is unclear, a person can mistake a per-app rule for a device-wide switch. Profiles add another layer: groups of apps can receive rules on chosen days and times. I would inspect both the immediate rule and its scheduled version, including how the app shows which connection type is affected. The roster establishes the available controls. The live Android product is where a visitor can check the confirmation and status the software actually gives before depending on a rule.
