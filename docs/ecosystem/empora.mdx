Empora groups WooCommerce modules in one WordPress plugin. The useful choice is at the merchant’s end: which modules to switch on for that store.

**The question:** Can a store install one plugin without adopting every module?

## What does the plugin contain?

The released product puts store modules in one plugin. The roster does not enumerate each module here, so I would send a merchant to the live product for its current list.

## Where does configuration happen?

A web dashboard handles licences and optional store connections. That makes the plugin and the management surface two parts of the same released workflow.

## Which decision stays with the merchant?

Modules can be switched on selectively. That is a more useful description than assuming every WooCommerce store wants the same set of additions.
