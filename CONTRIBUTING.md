# Contributing

## Report a problem

Open a [GitHub issue](https://github.com/aoneahsan/aoneahsan-portfolio-docs/issues) with the page URL, what is wrong, and a source for any factual correction. Do not include credentials or private account data.

## Propose a change

Fork the repository, create a branch, and open a pull request to `main`. Describe the content or code change and list the pages and screen widths you checked. A collaborator can also request access through the issue template, but access is granted by the owner.

For source changes, use Node 26 and Yarn 4. Run `yarn install --immutable`, `yarn typecheck`, and `yarn build`. Keep page descriptions, links and dated claims accurate. Use Conventional Commit subjects. Do not add GitHub Actions, secrets, generated `build/` output, or third-party tracking scripts.

The owner maintains the protected `main` branch directly. Outside contributions are reviewed through pull requests. Publishing to `gh-pages` is owner-maintained.

For product support, [contact Ahsan](https://aoneahsan.com/contact). To support his public work, use [aoneahsan.com/payment](https://aoneahsan.com/payment).
